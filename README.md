# Intro Video (Fabric 1.21.11, клієнтський мод)

Замість екрана завантаження Mojang показує відео з PNG-кадрів.

## 1. Підготуйте кадри

Експортуйте відео як послідовність PNG-зображень (DaVinci Resolve: Deliver -> Format: PNG,
Resolution 854x480 або 1280x720). Підійде будь-яка програма, імена файлів не важливі.
Головне, щоб у назвах був номер кадру з нулями (000001, 000002 ...), тоді порядок буде правильний.

Або через ffmpeg:

```
mkdir frames
ffmpeg -i video.mp4 -vf "fps=30,scale=854:-2" frames/frame_%04d.png
```

## 2. Покладіть кадри в гру

Скопіюйте ВСІ PNG сюди:

```
.minecraft/config/introvideo/frames/
```

(Папка створиться сама при першому запуску гри з модом.)

Мод бере всі `.png` з цієї папки в природному порядку, тож в папці не повинно бути сторонніх PNG.

## 3. Частота кадрів

За замовчуванням 30 кадрів на секунду. Якщо рендерили з іншою частотою, створіть файл

```
.minecraft/config/introvideo/fps.txt
```

з одним числом (наприклад `24`). Перезбирати мод не потрібно.

## 4. Зберіть мод

Потрібні Java 21 та Gradle 9.2.1+.

```
gradle wrapper --gradle-version 9.2.1
gradlew build
```

Готовий файл: `build/libs/introvideo-1.0.0.jar`. Покладіть його в `.minecraft/mods`.

Якщо Gradle скаржиться, що версія залежності не існує, відкрийте `gradle.properties`
і підставте актуальні `loader_version` та `loom_version` зі сторінки https://fabricmc.net/develop.

## Примітки

- Якщо кадрів немає, мод нічого не робить, гра завантажується як зазвичай.
- Відео не пропускається: екран завантаження закриється, коли відео закінчиться.
- Мод використовує офіційні мапінги Mojang. Якщо збірка падає на `blit` чи `DynamicTexture`,
  сигнатури цих методів у 1.21.11 могли відрізнятися. Надішліть текст помилки.
